# Step 4: Rebuild the Registry

## What is the Registry?

The file `tools/registry.json` is a machine-readable index of all tools and workshops in the repository. It is **never hand-edited** — it's always regenerated by the rebuild script.

## Run the Rebuild Script

From the repository root, run:

```bash
scripts/rebuild-registry.sh
```

You should see output like:

```
Registry generated at tools/registry.json with 3 tool(s) and 1 workshop(s).
```

## Verify Your Tool Appears

Check that your tool is listed:

```bash
jq '.tools[] | select(.slug == "my-example-tool")' tools/registry.json
```

You should see:

```json
{
  "slug": "my-example-tool",
  "path": "tools/my-example-tool",
  "manifest": "tools/my-example-tool/tool.json"
}
```

## Important

- Always run the rebuild script after adding or modifying a tool
- The registry must be committed alongside your tool changes
- CI will verify that the committed registry matches what the script would produce
