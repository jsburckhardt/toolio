# Creating Your First Tool

A beginner-friendly workshop that walks you through creating, packaging, and contributing a new tool to the Toolio repository.

## Overview

In this workshop, you will learn how tools are structured in Toolio, create your own tool from scratch, validate it against the schema, and submit it via a pull request.

## Prerequisites

- Basic Git knowledge
- Access to a terminal
- Repository cloned locally

## Learning Objectives

1. Understand the Toolio tool packaging structure
2. Create a `tool.json` manifest with required fields
3. Write a tool README with usage examples
4. Run the registry rebuild script
5. Submit a PR following the RPIV pipeline

## Estimated Duration

~30 minutes

## Steps

1. [Introduction](./steps/01-introduction.md) — What is a "tool" in Toolio?
2. [Create Tool Folder](./steps/02-create-tool-folder.md) — Set up the directory and manifest
3. [Write README](./steps/03-write-readme.md) — Document your tool
4. [Rebuild Registry](./steps/04-rebuild-registry.md) — Run the rebuild script
5. [Submit PR](./steps/05-submit-pr.md) — Submit following the RPIV pipeline
