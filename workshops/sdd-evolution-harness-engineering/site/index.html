From # write a function to Harness Engineering

A hands-on, lego-style workshop on how agentic coding actually evolves under load — from hashtag prompts to a full RPIV harness with guides and sensors.

⏱ ~3 hours (90 min condensed) 👥 Pairs — driver + navigator, swap every module 🎯 Advanced

The arc you’ll walk

Each module hits one transition in the one-year arc of how agentic coding evolves. Pay attention to what broke between stages — that’s where the value of the next stage lives.

# hashtag comments → file-as-context → agents (slop) → plan/implement ↓ research → plan → implement ↓ RPIV ↓ RPIV + shared architecture ↓ RPIV wrapped around upstream agents ↓ harness engineering

What you’ll learn

By the end you’ll be able to

  1. Articulate what each RPIV stage produces and consumes — without looking it up.
  2. Walk into a brownfield repo and stand up the minimum harness needed to run RPIV on it.
  3. Recognise when you need a guide (feedforward) vs a sensor (feedback), and whether a computational or inferential mechanism fits.
  4. Wrap an upstream agent (HVE Core, Copilot Workspace, anything) without forking it.
  5. Decompose a feature into parallel workitems that don’t trip over each other.

Prerequisites

  • A coding-agent CLI you’re comfortable with (Claude Code, OpenCode, Copilot CLI, etc.).
  • git, gh, and a Python or Node toolchain.
  • A GitHub account with gh auth login working.
  • ~15 min before the workshop: clone the base repo and create one throwaway issue.

Setup snippet

# Spin up your workshop repo
gh repo create soft-factory-workshop --template jsburckhardt/soft-factory --private --clone
cd soft-factory-workshop
gh issue create --title "Workshop test issue" --body "Throwaway issue for the workshop." --label workshop

The issue number you get back is your WI for the day. Examples assume 42 — substitute your own.

Format

Pairs. One driver, one navigator. Swap every module. Modules 0–4 are essentials (~110 min); 5–7 are stretch (~75 min); kata closes the loop (~10 min). For a 90-minute slot, run modules 0–2 + 8 only.
