Module 8 · Wrap up

Closing kata

⏱ 10 min Pairs, 5 min each direction No notes. No tabs open. Memory only.

You’ve walked the arc. Now check whether it stuck. Pairs — one person answers, the other listens and pushes back. Swap after 5 minutes.

Rules

Close the workshop tab. Close the cheat sheet. Phones face-down. If you have to look something up to answer, the workshop didn’t land for that question yet — circle back to that module.

The four questions

Question 1

What does Research produce, and who consumes it?

You should be able to answer this in one breath. If you can’t, revisit Module 2.

Question 2

What does Verify check against?

Hint: it’s not the code. It’s not the plan. It’s not your taste.

Question 3

Name one computational guide and one inferential sensor you’d add to your team’s repo on Monday.

Specifics. Not categories. “A pre-commit hook that forbids print() in src/”, not “a linter”.

Question 4

Your colleague forks an upstream agent because “it doesn’t fit our paths.” What do you say?

You should say something short, structured, and not preachy. Practice the sentence.

Cheat sheet (pin this after the kata)

Research  →  research.md  (what’s in the repo, what decisions exist, gaps)
Plan      →  plan.md      (what / where / why; cites research)
Implement →  code + tests (compliant with ADRs + core-components)
Verify    →  verify.md    (acceptance criteria, evidence, PR link)

Global, outside workitems:
  project/architecture/ADR/
  project/architecture/core-components/
  project/architecture/DECISION-LOG.md
  AGENTS.md       (the contract)
  CONTRIBUTING.md (how to use the contract)

Lego rule

Start with the base brick. Add components as the next-broken-thing tells you what to add.

You don’t need all four 2×2 quadrants on day one. You don’t need parallel worktrees on day one. You don’t even need ADRs on day one if your workitem fits in one head.

But the minute you feel drift, or the minute you re-discover a decision, or the minute two workitems collide — the next brick is right there. Pick it up. Snap it on.
