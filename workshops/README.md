# Workshops Catalogue

This directory contains hands-on workshops for learning how to use and contribute to Toolio. Each workshop is a subdirectory with a `workshop.json` manifest, a `README.md`, and a `steps/` directory with numbered step files.

## How to Add a Workshop

See [CONTRIBUTING.md](../CONTRIBUTING.md) for instructions on creating and submitting a new workshop.
